## How I work a problem

**Customer report → clarify → reproduce → investigate → resolve or escalate → verify → communicate → document**

I work across customer-facing production issues, integrations, ecommerce, QA and operational troubleshooting. The useful part is not knowing every answer immediately. It is reducing uncertainty quickly, collecting the right evidence, keeping the customer informed and leaving the next person with a better path.
